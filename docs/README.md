# Документация проекта Calista Tracker

Каталог содержит проектные и аналитические материалы в соответствии с требованиями ТЗ:

- `competitors/` — анализ конкурентов, таблица функциональности, каталог 15+ жалоб пользователей и выбор уникальной функции.
- `uml/` — UML-диаграммы в текстовом формате Mermaid (Use Case, Class Diagram, Component/Layers Diagram) с инструкцией по визуализации.
- `adr/` — архитектурные решения (Architecture Decision Records, минимум 4 ADR по ТЗ, в проекте — 6 ADR).
- `wireframes/` — макеты экранов приложения (ASCII / векторные wireframes).
