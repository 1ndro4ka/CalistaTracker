# ADR 0006: Организация локальных напоминаний и кроссплатформенной сборки (Android + iOS CI)

## Статус
Принято (Accepted)

## Контекст
1. **Напоминания:** трекер привычек бесполезен без своевременных напоминаний. Начиная с Android 13 (API 33) введено обязательное разрешение `POST_NOTIFICATIONS`, а на Android 14+ ограничена отправка точных будильников (`SCHEDULE_EXACT_ALARM`). При этом устройство может перезагружаться, сбрасывая системный AlarmManager.
2. **Сборка под iOS:** студент разрабатывает проект на Windows/Android без физического компьютера Mac. Требуется автоматизировать сборку под iOS для защиты проекта и проверки работоспособности через установку по Sideloadly.

## Принятое решение
1. **Уведомления:**
   - Использовать стек **`flutter_local_notifications` + `timezone` + `flutter_timezone`**.
   - Для Android регистрировать канал уведомлений высокой важности с виброоткликом, запрашивать разрешение `POST_NOTIFICATIONS` во время первого включения напоминания, использовать `AndroidScheduleMode.exactAllowWhileIdle`.
   - Добавить слушатель широковещательного намерения `BOOT_COMPLETED` для восстановления расписания после перезагрузки смартфона.
2. **iOS CI Pipeline:**
   - Настроить GitHub Actions workflow `build-ios.yml` на виртуальной машине `macos-latest`.
   - Выполнять сборку `flutter build ios --release --no-codesign`.
   - Автоматически упаковывать полученный `Runner.app` в директорию `Payload/` и генерировать файл `CalistaTracker.ipa`, выгружаемый в артефакты сборки.
   - Пользователь устанавливает данный IPA на свой iPhone через утилиту **Sideloadly** (персональный бесплатный Apple ID).

## Рассмотренные альтернативы
1. **Облачные Push-уведомления (Firebase Cloud Messaging / OneSignal):**
   - *Минусы:* требуют серверной инфраструктуры, наличия постоянного интернета и регистрации аккаунтов. Противоречит принципу 100% автономности приложения.
2. **Локальная сборка iOS через виртуальную машину macOS на Windows:**
   - *Минусы:* нестабильно, нарушает EULA Apple, требует огромных ресурсов ПК. Облачный GitHub Actions — стандарт индустрии.

## Последствия
- **Положительные:** гарантированная доставка уведомлений даже в спящем режиме Android (Doze mode); возможность студенту сдать проект с полноценным рабочим iOS-артефактом без затрат на покупку Mac или платного аккаунта разработчика Apple Developer ($99/год).
- **Отрицательные:** необходимость ручного обновления срока действия сертификата при установке через Sideloadly раз в 7 дней (стандартное ограничение бесплатного аккаунта Apple).
