# Чек-лист тестирования на реальном Android-устройстве

## 1. Подготовка
- [ ] Устройство на Android 13+ (проверить `Настройки → О телефоне`).
- [ ] Включена отладка по USB, устройство видно в `adb devices`.
- [ ] Установлен свежий APK: `adb install -r build/app/outputs/flutter-apk/app-release.apk`.
- [ ] Часовой пояс устройства — не UTC (например, Europe/Moscow).
- [ ] Отключён режим экономии заряда для приложения (иначе OEM может убивать будильники).
- [ ] Очищены старые данные: `adb shell pm clear com.calista.calista_tracker`.

## 2. Первый запуск и разрешения
| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| P1 | Первый запуск | Открывается «Сегодня», пустое состояние, skeleton не «зависает» | ☐ |
| P2 | Создание привычки без напоминания | Привычка появляется в списке, сохраняется после перезапуска | ☐ |
| P3 | Включение напоминания | Появляется системный запрос `POST_NOTIFICATIONS` | ☐ |
| P4 | Отказ от уведомлений | Привычка сохраняется, показывается предупреждение, приложение не падает | ☐ |
| P5 | Android 12+ | Запрашивается разрешение на точные будильники; при отказе — inexact-режим | ☐ |

## 3. Основные сценарии
| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| C1 | Отметить привычку на «Сегодня» | Чекбокс закрашивается, серия +1, haptic-отклик | ☐ |
| C2 | Снять отметку | Чекбокс очищается, серия пересчитывается | ☐ |
| C3 | Свайп карточки влево | Удаление с возможностью отмены через SnackBar | ☐ |
| C4 | Редактирование названия/расписания | Изменения видны сразу и после перезапуска | ☐ |
| C5 | Привычка «по будням» в выходной | Не отображается как запланированная, серия не рвётся | ☐ |
| C6 | Пустое название | Валидация не даёт сохранить, показывается ошибка | ☐ |
| C7 | Удаление привычки | Удаляются привычка и её история, уведомление отменено | ☐ |

## 4. «Гибкая серия»
| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| F1 | Пропуск 1 дня | При запуске создаётся `❄`-ячейка, серия сохраняется, `freezesRemaining` уменьшается | ☐ |
| F2 | Пропуск 2 дней при лимите 2 | Обе ячейки заморожены, серия сохраняется | ☐ |
| F3 | Пропуск 3 дней при лимите 2 | Серия рвётся, третья ячейка остаётся пустой | ☐ |
| F4 | 1-е число нового месяца | Квота заморозок сбрасывается | ☐ |
| F5 | Нажатие на замороженный день | Ячейка становится выполненной, счётчик заморозок уменьшается | ☐ |
| F6 | Нажатие на будущий день | Ничего не происходит (защита от случайных действий) | ☐ |
| F7 | Индекс стабильности | Замороженные дни не входят в числитель, но входят в знаменатель | ☐ |
| F8 | Граница года 31.12 → 01.01 | Серия и месячная квота считаются корректно | ☐ |
| F9 | 29 февраля високосного года | Нет падений и дублей дней | ☐ |

### Диагностика уведомлений

```bash
adb shell dumpsys notification --noredact | findstr calista
adb shell cmd alarm list | findstr calista
adb logcat -s flutter:V flutter_local_notifications:V
```
