# Макеты экранов (Wireframes) Calista Tracker

## Концепция интерфейса
- **Стиль:** Monochromatic Minimalist Design System.
- **Цвета:** Фон `#0A0A0A`, карточки `#141414`, акцентный текст и активные маркеры `#F4F4F5`, границы `0.5–1 px` `#27272A`, приглушённый текст `#71717A`.
- **Шрифт:** JetBrains Mono (моноширинный, табулярные цифры для серий, времени и метрик).

## 3. Экран создания / редактирования привычки

```
+---------------------------------------------------+
|  [ОТМЕНА]          НОВАЯ ПРИВЫЧКА      [СОХРАНИТЬ]|
+---------------------------------------------------+
|  НАЗВАНИЕ                                         |
|  [Например: Чтение книги 30 мин                 ] |
+---------------------------------------------------+
|  ОПИСАНИЕ (ОПЦИОНАЛЬНО)                           |
|  [Профессиональная литература перед сном        ] |
+---------------------------------------------------+
|  РАСПИСАНИЕ                                       |
|  (•) Каждый день    ( ) Выбранные дни недели      |
|                                                   |
|  [ПН]  [ВТ]  [СР]  [ЧТ]  [ПТ]  [СБ]  [ВС]         |
|   *     *     *     *     *     -     -           |
+---------------------------------------------------+
|  НАПОМИНАНИЕ                                      |
|  [x] Включить локальное напоминание               |
|  Время: [ 21 : 30 ]  (точный будильник)           |
+---------------------------------------------------+
|  ГИБКАЯ СЕРИЯ (STREAK PROTECTION)                 |
|  [x] Разрешить автозаморозку при пропуске         |
|  Лимит заморозок: [ 2 ] в месяц (1-го числа сброс)|
|                                                   |
|  (i) Заморозка автоматически защитит стрик от     |
|      обнуления, если день будет пропущен.         |
+---------------------------------------------------+
```
